# 🎒 유치원 등원 준비 대시보드 & 포켓몬 도감

태블릿(패드) 가로 화면용 아침 루틴 대시보드입니다. 정적 웹앱이라 GitHub Pages에 그대로 올릴 수 있어요.

## 파일 구성
```
index.html          메인 앱 (단일 HTML, 외부 의존 없음)
assets/task-1.png   아침 할 일(화장실) 일러스트
assets/task-2.png   가방 준비
assets/task-3.png   밥 먹기 (20분 타이머 카드)
assets/task-4.png   아침 공부
assets/task-5.png   양치하고 옷 입기
assets/pokemon/     도감용 포켓몬 공식 이미지 10종 (PokeAPI sprites, 학습·비상업적 용도)
```

## 배포 방법 (독서캘린더와 동일)
1. GitHub에 새 Public 저장소 생성 (예: `morning-dashboard`)
2. 이 폴더 내용을 `main` 브랜치 루트에 push
3. Settings → Pages → Source: `main / (root)` (새 저장소면 기본값)
4. `https://psy6742.github.io/morning-dashboard/` 접속

## 사용 규칙
- **진행 바**: 기상 06:45(0%) → 유치원 출발 08:10(100%), 기준은 ⚙️ 설정에서 변경 가능
- **EXP**: 시간 내(출발 전) 할 일 1개 완료 시 +10 EXP (5개 모두 = +50 EXP)
- **포획**: 누적 100 EXP마다 오늘의 목표 포켓몬 포획 → 도감 등록, 하루에 중복 적립 없음
- **밥 먹기 타이머**: 카드 안 20분 카운트다운 (시작/일시정지·끝·초기화), 새로고침해도 이어감
- **08:10 출발 음향**: 효과음 + "가랏, 피카츄!" 음성(안내) — 하루 1회, 🔊 소리 켜기로 활성화한 기기에서만 울림. ⚙️에서 미리 듣기 가능
- **날씨**: 답십리1동(37.5712, 127.0545) 기준 Open-Meteo 기온·상태·최고/최저·8/12/16/20시 예보 + 미세/초미세먼지 등급·수치 + 외출 팁 자동 생성
- **기록 저장**: 각 기기 브라우저 localStorage(`morningDashboard.v1`) — 지인과 공유해도 기록이 섞이지 않음
- **엄마용 ⚙️**: 기상/출발 시간 변경, 소리 켜기·미리 듣기, 시간 내 완료 테스트(+50 EXP), 포획 연출 바로 보기, 오늘 기록/도감 초기화

## 로컬 실행
```
python3 -m http.server 8899   # 폴더에서 실행 후 http://127.0.0.1:8899
```
(단순히 index.html을 더블클릭해도 동작하지만, 태블릿에서는 웹 주소 접속을 권장)
