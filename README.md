## 화면 구성 (v2 게임풍 디자인)
- **시간대 자동 전환**: 지금 시각에 따라 화면 전체가 바뀝니다 — **00:00~15:59 ☀️ 아침 루틴**, **16:00~23:59 🌙 저녁 루틴**. 태블릿을 켜 둔 채 16:00·00:00을 넘겨도 5초 안에 알아서 전환됩니다. 포켓몬 목표·EXP·도감은 두 화면이 **같은 것**을 씁니다.
- **배경**: 위쪽은 맑은 하늘색 + 흰 구름, 아래 카드 영역은 아이보리. 굵은 다크 테두리(#222B38)와 만화풍 그림자. **저녁 루틴**에서는 해 질 무렵 노을(남보라 → 자주 → 주황 → 크림)로 바뀌어 아이가 저녁이라는 걸 바로 알아챕니다(테두리·카드·글씨 규칙은 그대로).
- **상단**: 왼쪽에 몬스터볼 + `포켓몬 도감` 버튼과 EXP 미니 게이지, 소리·설정 아이콘 / 가운데에 날짜(19px)와 큰 디지털 시계(자간을 넓혀 한눈에 읽히게) / 오른쪽에 4단 날씨 카드.
  - **날씨 카드 4단**: ① `📍 답십리1동 ·` + `구글 날씨 ↗` + `네이버 날씨 ↗` + `미세·초미세` 등급 배지 ② 큰 아이콘·기온·상태 + `최고/최저` + 클릭하면 새로고침되는 `🔄 실시간 HH:MM` 배지 ③ 8·12·16·20시 4칸 예보(아이콘·기온·💧강수확률) ④ 연노랑 팁 바(옷차림 + 우산·마스크 추천 한 줄).
  - **한 화면 맞춤**: 헤더를 192px로 늘렸지만 `1180×820`·`1024×768` 가로 화면에서 진행 바와 할 일 5개 카드가 세로 스크롤 없이 한 화면에 들어옵니다.
- **진행 바**: `유치원 출발까지 OO분 남았어요` + 초록 바 끝에서 같이 움직이는 몬스터볼 + `같이 준비하자!` 말풍선 + 학교 아이콘. (몬스터볼은 `--p`(0~1)로 바 안쪽, 양끝 11px을 넘지 않게 움직이고, 말풍선은 `#p-bar-wrap` 안쪽 위에 고정되어 `#progress-card` 밖으로 나가지 않습니다.)
  - **좌우 영역 너비 고정**: `#p-left` 250px · `#p-school` 55px · `#btn-rest` 126px 로 고정해, `🏖️ 오늘 쉬는 날`↔`🎒 등원 날로 전환`처럼 버튼 글자가 바뀌어도 가운데 초록 바의 시작 위치·전체 길이는 두 모드에서 픽셀 단위로 같습니다.
- **할 일 카드 5개**: 번호 동그라미, 지금 차례 카드에 노란 테두리 + `같이 하자!` 말풍선 + 오늘의 목표 포켓몬. 캐릭터 일러스트는 카드 폭을 꽉 채움.
- **🌙 저녁 루틴 화면 (16:00~자정)**: 카드가 **4칸**으로 바뀌고 진행 바가 `🌙 취침까지 OO분 남았어요`(시작 16:00 → 취침 20:10, 몬스터볼 이동 방식은 아침과 동일)로 바뀝니다. 오른쪽 아이콘은 🌙, `🏖️ 오늘은 쉬는 날` 버튼은 숨김(저녁 루틴은 매일 같은 순서).
  - **카드 4개**: 1 `밥 먹기`(30분 타이머 + 20분 보너스) · 2 `샤워하기`(10분 타이머) · 3 `한글책 소리내어 읽기` · 4 `영어책 소리내어 읽기` — 남자아이 일러스트로 아침 카드와 같은 그림체.
  - `1180×820`·`1024×768` 모두에서 4카드가 세로 스크롤 없이 한 화면에 들어갑니다.
  - **아침 공부 카드**: 그림과 `아침 공부` 글자 아래에 **그날 요일의 공부 목록**이 알약(칩)으로 나옵니다 (예: `문어빵` `키즈팩토` `책 발자국` `ORT` `영어 씨앗`). 알약 글씨는 아이가 읽기 쉽게 **13.5px 굵은 글씨**이고, 알약마다 앞에 **미니 몬스터볼**(14px, 진행 바 몬스터볼과 같은 빨강·검정·흰색)이 붙습니다. 항목이 길면 알약 안에서 두 줄로 접혀 글씨가 잘리지 않고, 그림은 그만큼 위아래로 부드럽게 줄어 카드 밖으로 넘치지 않습니다. 목록은 ⚙️ 설정 → `📚 공부 목록`에서 요일별로 고칩니다.
- **요일별 아침 공부 목록 (기본값)** — `S.settings.study`의 요일 키(`0`=일 … `6`=토)마다 따로 저장되고, `/`로 나눈 항목이 카드에 하나씩 알약으로 나옵니다. 요일마다 완전히 독립된 칸이라 나중에 하루씩 따로 바꿔도 다른 요일은 그대로예요.
  - 월: `문어빵 / 키즈팩토 / 책 발자국 / ORT / 영어 씨앗`
  - 화: `문어빵 / 원리셈 / 책 발자국 / ORT / 영어 씨앗`
  - 수: `문어빵 / 키즈팩토 / 책 발자국 / ORT / 영어 씨앗`
  - 목: `문어빵 / 원리셈 / 책 발자국 / ORT / 영어 씨앗`
  - 금: `문어빵 / 책 발자국 / ORT / 영어 씨앗 / 우봉고`
  - 토: `책 발자국(그림) / ORT`
  - 일: `문어빵 / 원리셈 / 키즈팩토 / ORT / 영어 씨앗`
  - 등원 날·쉬는 날 구분 없이 **오늘 요일**의 목록이 보입니다(토·일은 쉬는 날 카드에서도 그 요일 목록).
- **도감**: 상단 `포켓몬 도감` 버튼으로 전환, 도감 화면 오른쪽 위 `← 등원 준비로 돌아가기` 버튼으로 복귀.
  - **100마리 도감**: 인기 포켓몬 100종(아르세우스·뮤·아쿠스타 포함, 전국도감 번호·공식 한국어 이름). 잡지 않은 포켓몬은 실루엣 + `???`, 다음 목표에는 `다음 목표` 배지.
  - **필터 칩**: `전체 (100)` / `잡은 포켓몬 (N)` — 도감 안쪽만 세로 스크롤되고, 상단 제목·칩은 고정. 도감 화면에서는 진행 바를 접어 카드를 넓게 보여줍니다.

## 사용 규칙
- **진행 바**: 기상 06:45(0%) → 유치원 출발 08:10(100%), 기준은 ⚙️ 설정에서 변경 가능
- **할 일 5가지 (등원 날)**: 1 화장실 · 2 가방 준비 · 3 밥 먹기(20분 타이머) · 4 아침 공부 · 5 양치하고 옷 입기
- **쉬는 날 (유치원에 안 가는 날)**: 주말·법정공휴일(대체공휴일 포함, 2026~2028 내장)·방학 기간·지정 휴일·당일 결석이면 자동으로 쉬는 날이 됩니다.
  - 진행 바가 `쉬는 날 루틴 🎈 오늘은 유치원에 안 가요!` + `N/5 완료`로 바뀌고 08:10 출발 음악은 울리지 않습니다.
  - 할 일 5가지가 **1 화장실 · 2 밥 먹기(30분 타이머) · 3 아침 공부 · 4 우유 마시기 · 5 양치하기** 로 바뀝니다(시간 제한 없음).
  - 진행 바 오른쪽 `⛱️ 오늘은 쉬는 날` / `🎒 오늘은 등원 날` 버튼으로 오늘 하루만 바로 바꿀 수 있습니다.
  - ⚙️ 설정 → `⚙️ 시스템` 탭에서 **방학·휴원 기간(시작~종료)** 과 **특정 휴일 날짜**를 추가·삭제할 수 있습니다.
- **EXP**: 시간 내(출발 전) 할 일 1개 완료 시 +10 EXP — 등원 날 5개 = +50 EXP, 쉬는 날도 5개 = +50 EXP
- **🌙 저녁 루틴 사용 규칙 (16:00 ~ 취침 20:10)**
  - 할 일 4개, **취침 시각(기본 20:10) 전에 끝내면 1개당 +10 EXP**(4개 = +40 EXP, 20분 보너스까지 받으면 하루 최대 +50 EXP).
  - **밥 먹기 20분 보너스**: 30분 타이머를 **시작해서 20분 안(남은 시간 10:00 이상)에 완료**하면 `+10`을 더 줘 **+20 EXP**. 카드 아래 배지가 `⚡ 20분 이내 +10 보너스` → `⚡ 지금 끝내면 +10 보너스!` → `⚡ +10 보너스 받았어요!` 로 바뀝니다. 타이머를 안 쓰고 바로 완료하거나 20분을 넘기면 +10만 받습니다.
  - **샤워하기 10분 타이머**, 밥 먹기 30분 타이머는 서로·아침 타이머와 **독립**입니다(`days[날짜].eve.timers.eat/shower`). 타이머 종료 11초 전 버저는 아침과 같은 유튜브 소리입니다.
  - **취침 시각이 지나면**: 카드를 눌러도 완료 표시만 되고 **0 EXP** (아침의 `출발 이후 = 0 EXP` 규칙과 같음). 이때는 보호자가 설정에서 인정해 줍니다.
  - 저녁 화면에서는 08:10 출발 노래가 울리지 않고, 화면 켜짐 유지(06:45~08:10) 범위도 그대로입니다.
- **🛡️ 깜빡한 할 일 포인트 인정 (보호자용)**: 아이가 제때 끝냈는데 화면 터치를 깜빡했을 때 ⚙️ 설정 → `⏰ 시간·포인트` 탭의 `🛡️ 깜빡한 할 일 포인트 인정`에서 그 할 일을 눌러 주면 완료(+10 EXP)로 인정됩니다.
  - **🎒 아침 루틴** 과 **🌙 저녁 루틴** 이 따로 나오므로, 저녁에 앉아 아침 기록도 함께 인정할 수 있습니다(하루 총 9개). 보너스가 붙은 저녁 밥 먹기는 칩에 `+20`으로 표시됩니다.
  - `⚡ 밥 먹기 20분 보너스 +10` 버튼: 밥 먹기를 인정한 상태에서 20분 보너스까지 인정해 줍니다(이미 받았으면 비활성).
  - 오늘 할 일이 칩으로 나오고, 앞의 표시로 상태를 바로 알 수 있습니다 — `✅ +10` 인정됨 · `⏰ +0` 마감 시각이 지나 0 EXP로 체크됨 · `○ +0` 아직 체크 안 됨.
  - 체크된 칩이나 아직 체크하지 않은 칩이나 **누르면 바로 완료 +10 EXP** — 메인 카드도 같이 완료로 바뀝니다. 이미 인정된 `✅` 칩은 다시 눌러도 EXP가 늘지 않습니다.
  - `✨ 완료 표시된 N개 모두 인정 (+N×10)` 버튼으로 출발 시각 뒤에 체크된 할 일을 한 번에 인정할 수 있습니다.
  - **메인 화면 규칙은 그대로**: 출발 시각(기본 08:10) 이후에 카드를 누르면 여전히 0 EXP입니다. 진행 바·출발 시각·출발 노래도 바뀌지 않습니다.
  - 100 EXP가 되면 설정을 닫고 포획 연출이 먼저 뜹니다. 잘못 인정했으면 설정을 닫은 뒤 메인 화면에서 그 카드를 한 번 더 눌러 취소할 수 있습니다.
- **할 일 완료 효과음**: 할 일 카드를 눌러 **완료로 바뀔 때마다** `assets/task-done.mp3`(피카츄)가 1회 재생 — 완료를 풀 때는 무음, 연속 터치는 `currentTime=0`으로 되감아 다시 재생. 소리가 아직 꾹 꾼 상태에서 바로 눌러도 들리도록 그 터치 안에서 오디오를 깨운 뒤 재생합니다.
- **포획**: 누적 100 EXP마다 오늘의 목표 포켓몬 포획 → 도감 등록, 하루에 중복 적립 없음
- **목표 고정**: 목표 포켓몬은 날짜와 상관없이 **잡을 때까지 그대로 유지**됩니다(며칠이 걸려도 같은 포켓몬, EXP도 이어짐). 잡는 순간(`S.targetId` 비움 → 새 목표 자동 선택) 그다음 포켓몬으로 넘어가고, 그 포켓몬도 잡을 때까지 고정됩니다. 목표는 `S.targetId`에 저장되고 백업 파일에도 함께 담기며, 이 값이 없는 옛 기록·옛 백업은 날짜 기준으로 목표를 새로 골라 저장합니다.
- **밥 먹기 타이머**: 카드 안 카운트다운 — **등원 날 20분 · 쉬는 날 30분** (시작/일시정지·끝·초기화, 새로고침해도 이어감). 쉬는 날로 바꾸면 아직 시작하지 않은 타이머는 30분으로 다시 맞춰집니다.
  - **↻(초기화) 버튼**: 양옆 `▶ 시작`·`⏹ 끝`과 높이를 맞추면서 아이콘만 17px·굵게 키워 한눈에 보이게 했습니다.
- **식사 타이머 종료음**: 유튜브 `VKDa227lMr0` (10 seconds timer with buzzer effect sound) **소리만**, 남은 시간이 **11초가 되는 순간 1회** 재생 — 10초 타이머 클립이 00:01 근처에서 버저로 끝납니다.
  - 노래(`Xm_lnAIclY0`)와 **별도의 2px 숨은 플레이어**(`#yt-timer`)로 관리합니다.
  - `▶ 시작`·`🔊 소리 켜기`·화면 터치 때 조용히 미리 깨워 두고, `d.timer.cue11` 플래그로 한 번만 울립니다.

## 네이버 날씨 중계 (Cloudflare Worker) — 선택

```
npx wrangler deploy cloudflare-worker.js --name naver-weather --compatibility-date 2024-11-01
# → https://naver-weather.<계정>.workers.dev
```
