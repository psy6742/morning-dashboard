# 🎒 유치원 등원 준비 대시보드 & 포켓몬 도감

태블릿(패드) 가로 화면용 아침 루틴 대시보드입니다. 정적 웹앱이라 GitHub Pages에 그대로 올릴 수 있어요.

## 파일 구성
```
index.html          메인 앱 (단일 HTML, 외부 의존 없음)
cloudflare-worker.js 네이버 날씨 중계 (Cloudflare Worker, 선택 — 설정에 주소를 넣으면 사용)
assets/task-1.png   아침 할 일(화장실) 일러스트
assets/task-2.png   가방 준비
assets/task-3.png   밥 먹기 (20분 타이머 카드)
assets/task-4.png   아침 공부
assets/task-5.png   양치하고 옷 입기 / 쉬는 날 양치하기
assets/task-milk.png 우유 마시기 (쉬는 날 4번째 루틴)
assets/task-done.mp3 할 일 완료 효과음 (피카츄)
assets/pokemon/     도감용 포켓몬 공식 이미지 100종 (PokeAPI official-artwork, 학습·비상업적 용도)
```

## 화면 구성 (v2 게임풍 디자인)
- **배경**: 위쪽은 맑은 하늘색 + 흰 구름, 아래 카드 영역은 아이보리. 굵은 다크 테두리(#222B38)와 만화풍 그림자.
- **상단**: 왼쪽에 몬스터볼 + `포켓몬 도감` 버튼과 EXP 미니 게이지, 소리·설정 아이콘 / 가운데에 날짜(19px)와 큰 디지털 시계(자간을 넓혀 한눈에 읽히게) / 오른쪽에 4단 날씨 카드.
  - **날씨 카드 4단**: ① `📍 답십리1동 ·` + `구글 날씨 ↗` + `네이버 날씨 ↗` + `미세·초미세` 등급 배지 ② 큰 아이콘·기온·상태 + `최고/최저` + 클릭하면 새로고침되는 `🔄 실시간 HH:MM` 배지 ③ 8·12·16·20시 4칸 예보(아이콘·기온·💧강수확률) ④ 연노랑 팁 바(옷차림 + 우산·마스크 추천 한 줄).
  - **한 화면 맞춤**: 헤더를 192px로 늘렸지만 `1180×820`·`1024×768` 가로 화면에서 진행 바와 할 일 5개 카드가 세로 스크롤 없이 한 화면에 들어옵니다.
- **진행 바**: `유치원 출발까지 OO분 남았어요` + 초록 바 끝에서 같이 움직이는 몬스터볼 + `같이 준비하자!` 말풍선 + 학교 아이콘. (몬스터볼은 `--p`(0~1)로 바 안쪽, 양끝 11px을 넘지 않게 움직이고, 말풍선은 `#p-bar-wrap` 안쪽 위에 고정되어 `#progress-card` 밖으로 나가지 않습니다.)
  - **좌우 영역 너비 고정**: `#p-left` 250px · `#p-school` 55px · `#btn-rest` 126px 로 고정해, `🏖️ 오늘 쉬는 날`↔`🎒 등원 날로 전환`처럼 버튼 글자가 바뀌어도 가운데 초록 바의 시작 위치·전체 길이는 두 모드에서 픽셀 단위로 같습니다.
- **할 일 카드 5개**: 번호 동그라미, 지금 차례 카드에 노란 테두리 + `같이 하자!` 말풍선 + 오늘의 목표 포켓몬. 캐릭터 일러스트는 카드 폭을 꽉 채움.
- **도감**: 상단 `포켓몬 도감` 버튼으로 전환, 도감 화면 오른쪽 위 `← 등원 준비로 돌아가기` 버튼으로 복귀.
  - **100마리 도감**: 인기 포켓몬 100종(아르세우스·뮤·아쿠스타 포함, 전국도감 번호·공식 한국어 이름). 잡지 않은 포켓몬은 실루엣 + `???`, 다음 목표에는 `다음 목표` 배지.
  - **필터 칩**: `전체 (100)` / `잡은 포켓몬 (N)` — 도감 안쪽만 세로 스크롤되고, 상단 제목·칩은 고정. 도감 화면에서는 진행 바를 접어 카드를 넓게 보여줍니다.

## 사용 규칙
- **진행 바**: 기상 06:45(0%) → 유치원 출발 08:10(100%), 기준은 ⚙️ 설정에서 변경 가능
- **할 일 5가지 (등원 날)**: 1 아침 할 일(화장실) · 2 가방 준비 · 3 밥 먹기(20분 타이머) · 4 아침 공부 · 5 양치하고 옷 입기
- **쉬는 날 (유치원에 안 가는 날)**: 주말·법정공휴일(대체공휴일 포함, 2026~2028 내장)·방학 기간·지정 휴일·당일 결석이면 자동으로 쉬는 날이 됩니다.
  - 진행 바가 `쉬는 날 루틴 🎈 오늘은 유치원에 안 가요!` + `N/5 완료`로 바뀌고 08:10 출발 음악은 울리지 않습니다.
  - 할 일 5가지가 **1 아침 할 일(화장실) · 2 밥 먹기(30분 타이머) · 3 아침 공부 · 4 우유 마시기 · 5 양치하기** 로 바뀝니다(시간 제한 없음).
  - 진행 바 오른쪽 `⛱️ 오늘은 쉬는 날` / `🎒 등원 날로` 버튼으로 오늘 하루만 바로 바꿀 수 있습니다.
  - ⚙️ 설정에서 **방학·휴원 기간(시작~종료)** 과 **특정 휴일 날짜**를 추가·삭제할 수 있습니다.
- **EXP**: 시간 내(출발 전) 할 일 1개 완료 시 +10 EXP — 등원 날 5개 = +50 EXP, 쉬는 날도 5개 = +50 EXP
- **할 일 완료 효과음**: 할 일 카드를 눌러 **완료로 바뀔 때마다** `assets/task-done.mp3`(피카츄)가 1회 재생 — 완료를 풀 때는 무음, 연속 터치는 `currentTime=0`으로 되감아 다시 재생. 소리가 아직 꾹 꾼 상태에서 바로 눌러도 들리도록 그 터치 안에서 오디오를 깨운 뒤 재생합니다.
- **포획**: 누적 100 EXP마다 오늘의 목표 포켓몬 포획 → 도감 등록, 하루에 중복 적립 없음
- **밥 먹기 타이머**: 카드 안 카운트다운 — **등원 날 20분 · 쉬는 날 30분** (시작/일시정지·끝·초기화, 새로고침해도 이어감). 쉬는 날로 바꾸면 아직 시작하지 않은 타이머는 30분으로 다시 맞춰집니다.
  - **↻(초기화) 버튼**: 양옆 `▶ 시작`·`⏹ 끝`과 높이를 맞추면서 아이콘만 17px·굵게 키워 한눈에 보이게 했습니다.
- **식사 타이머 종료음**: 유튜브 `VKDa227lMr0` (10 seconds timer with buzzer effect sound) **소리만**, 남은 시간이 **11초가 되는 순간 1회** 재생 — 10초 타이머 클립이 00:01 근처에서 버저로 끝납니다.
  - 노래(`Xm_lnAIclY0`)와 **별도의 2px 숨은 플레이어**(`#yt-timer`)로 관리합니다.
  - `▶ 시작`·`🔊 소리 켜기`·화면 터치 때 조용히 미리 깨워 두고, `d.timer.cue11` 플래그로 한 번만 울립니다.
  - `■ 끝` 또는 `↻ 초기화`를 누르면 즉시 멈추고 `cue11`도 초기화해 다음 타이머에서 다시 울립니다.
  - ⚙️의 `🔔 식사 타이머 소리 미리 듣기 / 정지` 버튼으로 그 소리를 그대로 확인할 수 있습니다.
  - **폴백**: 유튜브 재생이 안 되는 기기·차단 환경에서만 00:00에 기존 효과음(`playBeep`)이 대신 울립니다.
- **08:10 출발 음악**: 유튜브 `Xm_lnAIclY0` ([공식] 우리는 모두 친구) **소리만** 재생 — 하루 1회, 출발 후 2시간까지.
  - 재생 중에는 화면 위쪽 가운데에 `🎵 노래 정지` 버튼이 떠서 언제든 멈출 수 있습니다. ⚙️의 `🎵 우리는 모두 친구 미리 듣기 / 정지` 버튼으로 미리 확인·정지할 수 있습니다.
  - **자동재생이 막혀도 들리게**: ① 출발 시각이 되면 바로 재생을 시도하고, 1.6초 안에 시작되지 않으면 효과음(4음 차임)+`가랏, 피카츄!`가 대신 울립니다(오디오가 잠들어 있으면 먼저 깨움). ② 같은 순간 화면 위쪽에 **`🎵 출발 노래 재생하기`** 버튼이 떠서 아이패드가 자동재생을 막았어도 한 번만 터치하면 노래가 나옵니다. ③ 소리를 아직 안 켰으면 배너 문구가 **`🎵 출발! 노래 켜기`** 로 바뀝니다(터치 = 소리 켜고 재생).
  - **울리지 않던 문제 수정**: `refreshRest()`가 5초마다 돌면서 출발 시각이 지나면 `d.chime=true`를 먼저 찍어 버려 정작 `checkDepartEvent()`가 건너뛰던 버그를 고쳤습니다(이제 출발 판정은 `checkDepartEvent`만).
  - **출발 시각을 바꿈 때**: 이미 지난 출발 기록(`d.chime`)이 남아 안 울리는 일이 없도록, 새 출발 시각이 아직 안 지난 시점이면 오늘 기록을 지워 다시 울립니다.
  - **플레이어 크기**: 아이패드가 1×1px·`opacity:.01` IFrame을 '안 보이는 요소'로 보고 재생을 막는 경우가 있어, 화면 구석에 **2×2px·opacity .05**(실제 렌더 영역 안)로 두고 `playsinline:1`을 명시했습니다. `primeYouTube()`는 `pauseVideo()` 뒤 다음 tick에 `unMute()`를 하는 순서로 바꿨습니다.
  - 자동재생 대응: `🔊 소리 켜기`나 화면 첫 터치 때 `mute → play → pause → unMute`로 플레이어를 미리 깨워 둡니다.
  - **폴백**: 임베드 차단(101/150)·API 로드 실패·오프라인처럼 유튜브로 소리를 낼 수 없을 때만 기존 효과음 + `"가랏, 피카츄!"` 음성으로 대신 울립니다.
- **화면 켜짐 유지 (Wake Lock)**
  - **등원 날**: 기상(기본 06:45) ~ 출발(기본 08:10) 사이에만 화면을 켜 두고 **출발 시각 정각에 즉시 해제**해 아이패드의 원래 2분 자동 잠금이 그대로 돌아갑니다.
  - **쉬는 날**: 기상 이후 유지하다가 **5번 양치하기를 체크하는 순간 해제**합니다(체크를 풀면 다시 잡음).
  - 탭이 다시 보이거나 화면을 터치하면 그 조건에 한해 다시 잡습니다. 상태는 시계 아래 `화면 유지 중` 표시와 ⚙️ 설정의 `화면 켜짐 유지` 줄에서 확인할 수 있습니다(미지원 브라우저는 `이 기기에서 미지원`).
- **날씨**: 답십리1동(37.5712, 127.0545) 기준 — ①네이버 날씨 중계(기본 워커 주소가 들어 있어 별도 설정 없이 바로) → ②Open-Meteo → ③met.no 순서로 시도해 기온·상태·최고/최저·8/12/16/20시 예보 + 미세/초미세먼지 등급 + 옷차림·우산·마스크 팁을 채웁니다.
  - **네이버 날씨 중계**: `DEFAULT_WEATHER_PROXY`(`https://twilight-salad-4306.psy6742.workers.dev`)가 기본값이라 새 기기·새 브라우저에서도 주소를 입력할 필요 없이 가장 먼저 호출합니다(5초 타임아웃). 기존에 빈 문자열이 저장돼 있던 경우에도 사용자가 직접 비운 기록(`settings.proxyCustom`)이 없으면 자동으로 기본 주소를 채웁니다. 기온·상태 문구·최고/최저·오늘 시간대별 기온/강수확률·미세/초미세 등급을 네이버 값 그대로 쓰고, 배지가 `🔄 실시간 HH:MM · 네이버`로 표시됩니다. 주소가 죽어 있으면 조용히 Open-Meteo로 넘어가고 `· 네이버` 표시도 사라집니다.
  - **8·12·16·20시 4칸 고정**: 네이버는 '지금 이후' 시각만 내려주기 때문에, 오늘 날짜별로 4칸 스냅샷을 `localStorage`(`morningDashboard.hours.v1`)에 쌓아 두고 지난 시각(8·12·16시)은 아침에 받아 둔 값을 그대로 씁니다. 오후에 처음 열어 스냅샷에도 없으면 그 빠진 칸만 Open-Meteo의 오늘 08/12/16/20시 값으로 보충합니다(양쪽 다 없을 때만 `--°`). 라벨은 언제나 `8시·12시·16시·20시` 순서 그대로입니다.
  - **5초 타임아웃 + met.no 자동 폴백**: Open-Meteo가 5초 안에 응답하지 않으면 `api.met.no` locationforecast(compact)로 즉시 전환해 같은 항목을 채웁니다(met.no는 강수확률 필드가 없어 강수량으로 환산).
  - **미세먼지 분리 조회**: 대기질 API만 실패해도 날씨는 정상 표시되고, 배지는 `-`로 안전 표시됩니다.
  - **미세·초미세 배지 색(한국 기준)**: `좋음` = 파랑 `#3B82F6`(흰 글씨) · `보통` = 초록 `#22C55E`(흰 글씨) · `나쁨` = 노랑 `#FACC15`(진한 글씨 `#3F3200`) · `매우나쁨` = 빨강 `#EF4444`(흰 글씨). 네이버 등급 문구가 있으면 그 문구를 그대로 쓰고 색만 이 기준을 따릅니다.
  - **1시간 캐시**: 마지막 성공 날씨를 `localStorage`(`morningDashboard.weather.v1`)에 보관해 재방문 시 빈 화면이 없습니다. 모두 실패하면 `🔄 다시 불러오기` 버튼이 나타나고 10분마다 자동 재시도합니다.
  - **날씨 바로가기**: 카드 1줄의 `구글 날씨 ↗` → https://www.google.com/search?q=서울+동대문구+답십리1동+날씨, `네이버 날씨 ↗` → https://weather.naver.com/today/09230105 (모두 새 탭)
  - **실시간 배지**: `🔄 실시간 HH:MM`을 누르면 바로 새로고침합니다. 네이버 중계 값이면 `· 네이버`, met.no 폴백 값이면 `· 보조`, 이전 값을 그대로 보여주는 중이면 `· 캐시`가 붙습니다.
- **기록 저장**: 각 기기 브라우저 localStorage(`morningDashboard.v1`) — 지인과 공유해도 기록이 섞이지 않음
- **백업 · 복원 (JSON)**: 도감 상단 `💾 백업` 또는 ⚙️ 설정 → `💾 백업 파일 저장 (.json)` / `📂 백업 파일 불러오기`
  - 백업 파일에는 잡은 포켓몬(`caught`), 날짜별 진행 기록(`days` — 할 일·EXP·타이머·출발 알림), 오늘 진행 상태·다음 목표(`today`), 설정(`settings` — 기상/출발 시간, 소리)이 담깁니다.
  - 불러오기는 형식을 검사한 뒤(모르는 포켓몬·깨진 날짜는 건너뜀) 확인 창을 거쳐 복원하고, **복원 전 기록은 `morningDashboard.beforeRestore.v1`에 자동 보관**합니다. 이 대시보드 백업이 아니거나 내용이 없으면 복원하지 않고 안내만 합니다.
  - 기기를 바꾸거나 도감을 초기화하기 전에 파일로 저장해 두면 그대로 되살릴 수 있습니다.

## 네이버 날씨 중계 (Cloudflare Worker) — 선택
`cloudflare-worker.js`는 `https://weather.naver.com/today/09230105` HTML 안의 `var blockApiResult = {...};`를 읽어 필요한 값만 JSON으로 돌려주는 중계입니다(브라우저에서 네이버를 직접 부를 수 없어 CORS 때문에 필요).

```
npx wrangler deploy cloudflare-worker.js --name naver-weather --compatibility-date 2024-11-01
# → https://naver-weather.<계정>.workers.dev
```

1. 기본값으로 `https://twilight-salad-4306.psy6742.workers.dev`가 들어 있으므로 보통은 설정할 것이 없습니다. 직접 만든 다른 워커를 쓰려면 대시보드 ⚙️ 설정 → `네이버 날씨 중계 주소 (Cloudflare)`에 주소 입력 → `저장 및 새로고침`
2. 배지가 `🔄 실시간 HH:MM · 네이버`로 바뀌면 연결된 것 (주소를 비우고 저장하면 Open-Meteo·met.no로 돌아갑니다)

응답 예 (`Cache-Control: public, max-age=300`, `Access-Control-Allow-Origin: *`, `GET`/`OPTIONS`):
